1. 기본 할일 관리
- 일일: 매일 자정(00:00)에 자동 체크 해제
- 주간: 매주 화요일 17:00에 자동 체크 해제

2. 커스텀 그룹/이벤트
- ⚙️ 수정 버튼 > [+ 새 그룹 추가]로 생성
- 기간이 있다면 날짜를, 없다면 '기간 없음(상시)' 체크
- 날짜는 'YYYY-MM-DD'로 직접 입력 (예: 2023-1-9 도 가능)
- 기간이 만료되면 목록이 사라지지 않고 어둡게 표시됨
- 이벤트 내부에서 매일/매주/기간 내 할 일을 나눠서 관리 가능
- 만료된 항목은 제목 옆 [X]버튼으로 즉시 삭제 가능
- 입력창 앞 체크박스를 해제하면 텍스트만 표시됨 (단순 메모용)

3. 수치 카운터
- 점수 모으기, 횟수 채우기 등에 사용
- 카운터 이름 옆 숫자는 [시작수치]/[목표수치]를 나타냄(수정가능)
- 각 수치 카운터를 추가할 때 [%](퍼센트)와 [■](진행바) 버튼을 눌러 개별적으로 켜고 끌 수 있습니다.
- 버튼 추가 방법: 추가하고 싶은 수치 입력. 여러 버튼 추가시 쉼표(,)로 구분
- 카운트다운(차감)은 버튼에 '-1' 입력

4. 추가 설정 (자동 접기, 애니메이션)
- 설정창 하단에서 '자동 접기', '애니메이션' 설정 가능
- 마우스가 목록을 벗어나면 설정한 시간 뒤 자동으로 접힘
